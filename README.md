# AgentForge Labs Homebrew Tap

This tap contains Homebrew formulae for AgentForge Labs command-line tools.

Install SnapForge CLI:

```sh
brew tap AgentForge-Labs/homebrew-tap
brew install snapforge
```

Update with `brew update && brew upgrade snapforge`.

The SnapForge formula installs versioned public artifacts from `https://snapforge.web-tasarimci.com/cli-releases/` and verifies the pinned SHA256 for each supported platform. Downloads do not require a Homebrew account or package registry credentials.
